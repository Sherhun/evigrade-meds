How this page works

1. The page calls chrome.runtime.sendMessage({type: 'LOOKUP', payload}), exactly like content/detector.js does on iHerb / Amazon / VitaminShoppe.

2. The background service worker calls evigrade.com/api/meds/lookup with a 7-day LRU cache in chrome.storage.local. Repeat lookups for the same product return instantly from cache.

3. The result is rendered using the same overlay template (content/overlay.html) that ships on retailer pages.
